# Tennessee Eastman process: calibrated fault-hypothesis sets and a small RiskGate decision layer

Generated by `benchmarks/tep/run.py` from `results/tep_results.json`.

## What is real, what is rule-derived, what is simulated

| Component | Status |
|---|---|
| Plant data | **simulated** closed-loop Tennessee Eastman process (Downs & Vogel model), not a real plant. Braatz data: one run per fault (IDV 0-21). Rieth et al. 2017: 500 independent runs per fault (IDV 0-20). Fault labels are the simulator's. |
| Fault-hypothesis scorer | LLM-free regularised Gaussian discriminant (RDA) on 2-h window statistics, fitted on TRAINING files only; design fixed by cross-validation on the Braatz training files |
| Plausible sets | split conformal on held-out test windows (Braatz: time blocks; Rieth: runs) |
| `hold` labels | **data-derived**: the recorded run is the no-intervention outcome; unsafe iff reactor pressure exceeds the Downs & Vogel normal operating limit (2895 kPa) within the next hour |
| `rcw_up`, `feed_cut` labels and effects | **rule-derived** effect table from the IDV definitions (below) |
| Doer (policy mode) | **scripted** playbook on the scorer's top-1 diagnosis |

Licences: Braatz TEP data (one run per fault); repository licence covers software and documentation, data licence unclear: research use only, not redistributed. Rieth, Amsel, Tran, Cook (2017), Harvard Dataverse doi:10.7910/DVN/6C3JR1, public-domain dedication. No data are redistributed (the Rieth cache under `benchmarks/tep/cache/` is git-ignored).

> [!IMPORTANT]
> **Exchangeability.** The Braatz data contain ONE run per fault: calibration and evaluation windows of a fault come from the same run (split by contiguous time blocks), so Braatz coverage numbers are optimistic for a new occurrence of that fault. The Rieth study splits by run (500 runs per fault available; 100 used for the sets, 30 for decisions) and is the one to quote.

**Findings.**

1. With runs as the exchangeable units (Rieth), marginal split-conformal coverage is on target: 95.0% +- 0.3% at delta = 0.05, 90.0% +- 0.4% at delta = 0.1, 80.1% +- 0.4% at delta = 0.2. The Braatz time-block numbers look similar but rest on one run per fault.
2. Humility where the data are silent: for the undetectable IDV 3, 9 and 15 the delta = 0.1 set holds 3.5 classes on average (typically {0, 3, 9, 15}, often IDV 4), against near-singletons for IDV 1, 2, 6, 7 (per-class sizes 1.06, 1.03, 1.00, 1.00).
3. Marginal coverage is not conditional coverage: at delta = 0.1 the hard faults are covered 78.1%, normal operation 77.3%, IDV 5 41.1%, the first 2-4 h after onset 83.7%. Class-conditional calibration restores ~90% per class (hard 90.0%) at the price of larger sets (hard 5.2 classes).
4. IDV 4 and 5 are 'easy' detection faults, but this frozen scorer confuses them with normal operation on part of the Rieth runs (top-1 68.9% and 41.8%; Braatz: 100.0% and 97.4%). The steps are in the data (post-hoc check, 50 runs: reactor cooling-water flow XMV 10 41.1 -> 44.86 under IDV 4, condenser flow XMV 11 18.12 -> 20.86 under IDV 5; sample sd 0.54 and 1.46), so this is an efficiency loss of the scorer, which conformal calibration turns into larger sets rather than wrong certainties.
5. Decision layer (Rieth, alpha = 0.1): certifying everything is unsafe in 37.7% of decisions; every gate stays far below alpha. RiskGate lowers the unsafe rate relative to top-1 + CRC (1.3% vs 1.6%) and pays with asks (9.3% vs 8.0%): a trade-off, not a dominance. At alpha = 0.01 both calibrations move lambda-hat to ~1 and ask on 24.7% (RiskGate) and 23.1% (top-1) of the fixed split's test decisions. Residual unsafe certifications come from the hold model under-predicting the 1-h pressure rise of IDV 6/18 runs and from misidentified IDV 16/18 windows (per-class table below).

## Design (fixed before any test file was scored)

| window | LDA (shrinkage) | RDA g = 0.5 | RDA g = 0.8 |
|---|---|---|---|
| 10 samples (30 min) | 0.649 | 0.767 | 0.760 |
| 20 samples (1 h) | 0.683 | 0.809 | 0.798 |
| 40 samples (2 h) | 0.731 | **0.866** | 0.847 |

Time-block cross-validated top-1 accuracy on the Braatz TRAINING files (4 contiguous blocks per run), features = mean and
log sd of the 52 standardised variables. Exact CV log-loss of RDA (g = 0.5, 40 samples) by softmax temperature
T = 1 / 4 / 8 / 16 / 32: 5.64 / 1.79 / 1.34 / **1.30** / 1.48, hence T = 16.

Final: window 40 samples, a decision every 20 samples (1 h), mean + log sd of 52 standardised variables, RDA gamma=0.5, temperature=16.0; nonconformity r(h) = -log p(h | window). Hypothesis set = {h : r(h) <= tau}.

## 2. Decision layer (small, partly rule-derived)

Candidate responses to an upset: `hold` (keep set-points), `rcw_up` (raise the reactor cooling-water flow set-point), `feed_cut` (reduce the A/C feed, stream 4); `escalate` is the gate's ASK and is never gated. RiskGate certifies a response only if its robust margin (worst case over the plausible fault set) clears the calibrated threshold.

| response | unsafe under (rule-derived unless stated) | gate's consequence model |
|---|---|---|
| hold | **data**: recorded reactor pressure > 2895 kPa within 1 h | p_now + q95 of the 1-h pressure rise under the hypothesised class in the TRAINING runs, vs 2895 kPa (margin in 100 kPa) |
| rcw_up | IDV 6, 14, 16, 17, 18, 19, 20 | same table (+1 safe / -1 unsafe) |
| feed_cut | IDV 6, 7, 16, 17, 18, 19, 20, 21 | same table (+1 safe / -1 unsafe) |

* IDV 6: A feed loss: reactor pressure runs into its limit in the recorded runs; extra cooling slows the gas-consuming reactions (pressure up) and cutting stream 4 removes the remaining A supply.
* IDV 7: C header pressure loss: stream-4 supply is already reduced; cutting it further starves the reactor.
* IDV 14: reactor cooling-water valve sticking: moving its set-point provokes stick-slip jumps in cooling.
* IDV 21: stream-4 valve fixed: a feed cut cannot be executed, the plant would be believed mitigated when it is not.
* IDV 16: IDV 16-20 are of unknown type: no validated response exists, so any active intervention counts as unsafe.

## Caveats

* **Simulated plant.** Both datasets come from the Tennessee Eastman simulator; fault magnitudes, sensor noise and the control structure are the simulator's. Nothing here is evidence about a real plant.
* **Braatz exchangeability.** One run per fault; time blocks of one run are dependent and non-stationary (transients after onset), adjacent windows share samples. Rieth results (runs as units) are the defensible ones.
* **Conditional coverage.** Marginal conformal coverage is an average over classes and times: hard faults (IDV 3, 9, 15) and the first hours after onset are under-covered unless sets are calibrated per class, which inflates the sets of normal-looking windows to several classes (the honest answer: these faults are not identifiable from these data).
* **Decision layer is illustrative.** Active-response effects are a rule table, not a simulation; only `hold` uses recorded outcomes. Because the table makes most uncertainty fall between benign classes (0, 3, 9, 15), the top-1 twin gate is already competitive here; the layer shows how the calibrated set enters the decision, not a plant-ready policy.
* **Design reuse.** Hyper-parameters were chosen on the Braatz training files and reused for Rieth (refitted on Rieth training runs); no tuning on test files.
